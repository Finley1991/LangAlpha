# F4：个股新闻来源

2026-10-17 更新。当前范围只在手动生成的本地模拟日报中采集可回查的个股新闻，不据此生成买卖判断。持仓代码属于个人投资资料；仅当 `SIMULATION_NEWS_ENABLED=1` 时逐持仓查询。雪球和百度贴吧暂不采集，后续若要纳入再单独评估。

## 来源选择

- Tushare [`news`](https://tushare.pro/document/2?doc_id=143)、[`major_news`](https://tushare.pro/document/2?doc_id=195) 提供多来源按时间查询的新闻快讯/通讯，但接口不支持按单只证券代码过滤，且需额外开通“新闻资讯”权限。现有 Tushare 授权仅用于交易日历和历史日线，因此不用于本功能。
- 新浪财经个股新闻列表与详情 API 由用户提供并完成公开样例连通验证。列表中的 `comos:` 前缀按接口约定剥离后查询详情；只从详情 HTML 提取最多 320 字符摘要，不保存全文。请求使用固定 HTTPS 主机、关闭重定向，响应上限 512 KiB；每个持仓最多取 10 条列表记录并请求前 3 条详情。
- AKShare [文档](https://github.com/akfamily/akshare/blob/main/docs/data/stock/stock.md)提供东方财富 `stock_news_em(symbol)` 个股新闻入口；[适配源码](https://github.com/akfamily/akshare/blob/main/akshare/news/news_stock.py)展示其公开接口形态。产品使用轻量 HTTPX 适配器，不安装 AKShare/Pandas/Curl-CFFI，也不复制其源码中的 Cookie。只保存标题、短摘要、发布时间、媒体名和 HTTPS 原文链接；每只证券最多保留 5 条。
- 新浪也继续负责用户此前提供的公告与研报元数据接口；公告、机构观点与一般个股新闻分别标注。

## 运行和保存

查询仅由手动生成报告触发；每证券最多保留 5 条新浪新闻和 5 条东方财富新闻，最多处理 20 个持仓，总时限 25 秒。新浪最多请求前 3 条详情，不保存全文。外部失败以脱敏类别显示；成功结果连同来源、取数时刻和摘要标识冻结进本地报告，历史报告不重写。网页搜索服务不用于该新闻采集流程。

前端标注新闻为未核实材料并提供原文链接。新闻摘要不构成公司正式披露或事实结论。来源空白或接口错误保留待核实。报告状态、账本、订单和成交均不由该数据改变。

此方案针对本地个人验证。开源采集代码不等于来源网站数据可自由再分发；公开或商业使用前需单独核验网站条款、数据授权、搜索服务费用及接口稳定性。
