# F4 收盘证据接入

2026-10-15。沿用现有手动报告、账户版本和不可覆盖 JSON 证据；不启用 R2 成交、F5 通知或定时任务。已有新浪状态解析、状态测试和 execution design 保留原样，不纳入本轮改动。

## 数据与契约

服务端从认证用户账本取得代码；请求仍只接受 UUID 和账本版本，不接受客户端报价。`SIMULATION_CLOSING_ENABLED=1` 和运行时注入的 `TUSHARE_TOKEN` 同时存在才请求供应商；请求路径不读取任何凭据文件。默认关闭。

沪深日历分别查询 SSE/SZSE 最近 46 个自然日，要求完整、不重复、日期及交易所一致。从截止时刻以前已经结束的交易日中选最近一日（北京时间 15:00）；盘中取上一已结束交易日，休市取最近已结束交易日，不凭工作日推算。北交所暂标记缺失。

按交易所批量读取最多 100 项持仓的目标日 `daily`，代码、日期、唯一性与两位价格精度校验。无日线、权限错误、超时与异常明确展示，不用旧价回退，不把空记录推断为停牌。两交易所最多四次有界 HTTPS 调用、请求间隔 1.3 秒、整体 25 秒期限，无自动重试；前端生成超时 35 秒。

报告新增可空 `closing_price`；来源扩展为收盘价和日历，可回查查询参数、选定公开响应字段、数据对应时间、取数时间及摘要。旧 v1 报告字段兼容，不重写历史。收盘价不用于当前成交、当前市值、浮动盈亏或投资效果推断；原有三个公告/论点/档案缺口继续待核实。

## 保存与竞争

第一段账户事务验证请求/版本并冻结账本；释放锁后获取供应商证据；第二段事务先回读同 UUID 的已保存结果，再检查当前版本、账户和北京时间日期后保存。网络期间账本改变或跨日则拒绝保存。并发同键只持久化一份报告；并发首次请求可能重复只读查询，但不重复记账。重试已完成请求不再调用供应商。取消请求会关闭客户端，不保存半成品；整体超时保存已核验部分并明确缺失项。

不新增迁移、依赖或进程内所有权状态。已有报告请求幂等、校验失败隐藏缓存和历史失效规则保持有效。

2. 实现日历/收盘校验、报告两段事务、来源冻结与前端来源展示。
3. 公开样例真实 HTTPS 核验；独立 PostgreSQL 验证幂等、锁释放、版本竞争、跨日、回滚及隔离，补固定契约回归。
4. 前端类型/lint/test/build、虚构页面验证，核对已有三个文件未变，更新 OPC_AI 证据。F4 完整日报仍不勾选。

U5 仅覆盖公开样例；其后用户通过 U6 明确授权本地日报查询持仓证券历史日线与日历，已在用户实例启用并验证；不扩大为成交、定时任务或公开服务。
